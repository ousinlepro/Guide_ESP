Ce qu'est un test d'entrée

  • Un test d'entrée n'est pas un concours : on franchit une barre d'admission, on ne se bat pas pour un rang.
  • Une question facile rapporte autant qu'une difficile. Ne jamais rester bloqué.
  • Objectif réaliste : 12 à 14 sur 20 en note pondérée, pas la perfection.

Technique QCM

  • Éliminer d'abord : deux distracteurs sautent presque toujours.
  • Physique : vérifier l'homogénéité et l'ordre de grandeur, sans calcul.
  • Maths : tester une valeur particulière (x = 0, x = 1, n = 1) plutôt que tout résoudre.
  • Sans malus annoncé, aucune case vide : une réponse au hasard vaut 25 % d'espérance.
  • Français : la faute porte souvent sur un seul mot entre deux phrases presque identiques.
  • « Aucune des réponses » : rarement juste, mais pas jamais.

Gestion des 3 heures (4 matières)

  • 1er passage (≈ 90 min) : seulement ce qui se règle en moins d'une minute. Marquer le reste.
  • 2e passage (≈ 60 min) : les questions marquées, maths et physique d'abord (coefficients 3).
  • Dernier quart d'heure : reporter, vérifier qu'aucune ligne n'est décalée sur la grille.
  • Français et anglais se traitent vite : les faire tôt, ce sont des points sûrs.

La veille et le matin

  • Aucun chapitre nouveau : fiches, erreurs passées, épreuves blanches.
  • Arrêter à 20 h la veille, dormir normalement. Le matin : cette fiche, dix minutes.
  • Pièce d'identité ou carte d'étudiant, convocation, plusieurs stylos, une montre.
  • Arriver à l'ESP (UCAD, Corniche Ouest) largement en avance.

Accord du participe passé — les 6 règles qui tombent

Le cœur du programme QCM

  • Avec être : accord avec le sujet. « Elles sont arrivées. »
  • Avec avoir : accord avec le COD seulement s'il est placé avant. « Les lettres qu'elle a écrites. »
  • Suivi d'un infinitif : accord si le COD fait l'action. « Les fleurs que j'ai vues pousser » / « les airs que j'ai entendu chanter ».
  • Fait et laissé + infinitif : toujours invariables. « Elle s'est fait mal. »
  • Pronominaux : accord si le pronom est COD. « Elles se sont lavées » mais « se sont lavé les mains », « se sont souri », « se sont succédé », « se sont rendu compte ».
  • Impersonnels (falloir, pleuvoir, y avoir) et coûté, valu, pesé, vécu, couru au sens propre : invariables.

Orthographe, homophones, conjugaison

Accords délicats

  • Couleur composée : invariable (vert clair, bleu foncé, jaune citron).
  • Adjectif composé avec adverbe : 1er élément invariable (court-vêtues, nouveau-nés).
  • Tout adverbe : invariable devant voyelle (tout étonnées), accordé devant consonne ou h aspiré (toutes honteuses).
  • Demi : invariable avant (une demi-heure), accordé en genre après (deux heures et demie).
  • Vingt, cent : « s » seulement si multipliés et non suivis d'un nombre (quatre-vingts, deux cent trois).
  • Quel que + être, accordé avec le sujet (quelles que soient) ; quelque = environ.
  • En -aux : bail, corail, émail, soupirail, travail, vantail, vitrail. Mais sérail → sérails, détail → détails.

Homophones

  • quand (lorsque) · quant à (en ce qui concerne) · qu'en
  • plutôt (de préférence) · plus tôt (≠ plus tard) — peut être (verbe) · peut-être (sans doute)
  • quoique (bien que) · quoi que (quelle que soit la chose que)
  • leur (pronom devant le verbe, invariable) · leurs (déterminant, accordé)

Conjugaison

  • Jamais de conditionnel après « si » : si + présent → futur ; si + imparfait → conditionnel présent ; si + plus-que-parfait → conditionnel passé.
  • Subjonctif après bien que, quoique, avant que, pour que, il faut que. Indicatif après après que.
  • Le « i » signale l'imparfait : nous conquérions, nous criions (présent : nous conquérons).
  • Passés simples piégés : il résolut, il conquit, il vainquit, il naquit, il mourut.
  • Subjonctifs piégés : que vous fassiez, que nous soyons, que vous ayez, qu'il aille.

Anglais

coef 1surtout les temps verbaux

Les temps — la matière n°1 de l'épreuve

Quand employer quoi

  • Present simple : habitude, vérité générale, horaire (« The train comes at 10 »).
  • Present continuous : action en cours, projet organisé (« I'm meeting him tomorrow »).
  • Present perfect : bilan, résultat présent ; since + point de départ, for + durée.
  • Present perfect continuous : durée d'une action encore en cours (« has been waiting for 15 min »).
  • Preterit : fait passé daté (yesterday, ago, last week, in 1998) — jamais de present perfect avec ces repères.
  • Past perfect (had + PP) : antériorité dans le passé (« When he arrived, the party had begun »).
  • Past perfect continuous : durée avant un moment passé. Future perfect : « By 2030, she will have finished ».

Conditionnels

  • Type 1 : If + présent, will + BV · Type 2 : If + prétérit (were partout), would + BV · Type 3 : If + past perfect, would have + PP.
  • If only + past perfect = regret · unless = if… not · jamais de « will » après « if ».

Connecteurs, modaux, faux amis

Connecteurs

  • because + proposition · because of / due to / owing to + nom
  • although / though + proposition · despite / in spite of + nom ou -ing
  • so that / in order that + proposition · so as to / in order to / to + BV
  • however, nevertheless, therefore : adverbes de liaison, suivis d'une virgule

Modaux

  • mustn't = interdiction ≠ don't have to = absence d'obligation · must = quasi-certitude ≠ can't = impossible
  • should have + PP = reproche ou regret · Après make et let (actif) : BV sans « to »

Gérondif, infinitif, faux amis

  • Après une préposition : -ing (about, without, before, look forward to).
  • enjoy, avoid, mind, suggest, finish, practise + -ing · want, hope, decide, promise, agree + to + BV
  • stop + -ing (cesser de) ≠ stop to + BV (s'arrêter pour)
  • Faux amis : actually = en fait · currently = actuellement · attend = assister à · sensible = sensé · sensitive = sensible · library = bibliothèque · pass an exam = le réussir · sit for an exam = le passer
  • make a mistake, progress, a decision — do homework, research · much / less + indénombrable, many / fewer + dénombrable
